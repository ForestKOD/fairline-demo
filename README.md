# Fairline — демо оновленої вітрини

Інтерактивний прототип для обговорення з клієнтом. Показує, як працюватиме оновлений
інтернет-магазин за ТЗ від 12.10.2026. Товари, бренди й ціни вигадані.

## Що можна подивитися

| Сторінка | Що демонструє |
| --- | --- |
| `index.html` | Динамічна сезонна добірка (перемикається за датами, лише товари в наявності, закріплені позиції), чисте дерево розділів |
| `catalog.html` | Фільтри за нормалізованими атрибутами: OR усередині групи, AND між групами, лічильники, приховані порожні значення, «Скинути все», висувна панель на мобільному; пошук за артикулом (`?q=`); акції лише з реальними знижками (`?sale=1`) |
| `product.html?id=16` | Розміри як варіанти з окремим залишком, недоступний розмір не додається в кошик, ціна «5 490 ₴», статуси наявності, таблиця характеристик, схожі товари |
| `admin.html` | Панель постачальників: «Синхронізувати зараз», статистика, журнал, «Потребує зіставлення», захист ручних правок |

## Як запустити

Просто відкрийте `index.html` у браузері — сервер і збірка не потрібні.

Або увімкніть GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Структура

```
index.html, catalog.html, product.html, admin.html
assets/style.css   — стилі (мотив туристичного маркування стежок)
assets/data.js     — демо-товари, категорії, добірки
assets/app.js      — вітрина: картки, фільтри, рекомендації, кошик
assets/admin.js    — демо панелі синхронізації
```

У робочому проєкті ця логіка переноситься в модулі OpenCart: імпорт постачальників,
рекомендації, фільтри та правки теми.
